Game Summary

Game workflow & scoring

Set the game and pitcher. Tap a lineup spot, enter its hitter name/jersey, and choose Left or Right. Select the call, mark both execution questions, then choose the result. Record Pitch commits the complete pitch and updates the count. Called pitch and location stay selected; execution and result clear.

Use Substitute Hitter to add a new player to the current spot or return a player previously subbed out of that spot. History stays separate for each player. A mid-at-bat substitution preserves the count and full plate appearance pitch total. There is no pitch limit per at-bat; every foul is logged. Name edits correct a player’s name; they do not create a substitute.

Strike % = called strikes + swinging strikes + fouls + balls in play divided by all recorded pitches. Balls in play are included as strikes regardless of hit/out; hit by pitch is excluded from strikes. Correct pitch % and location % are independent execution scores across all pitches. A foul IS a recorded game pitch and counts as a strike for game pitch statistics. A two-strike foul does not increase the count. This differs from the hitting drill tracker.

Hitter swing/miss information is shown as counts, not a recommendation. Hard/Weak and trajectory are coach observations. Fly Ball includes popups. Out includes a routine out, sacrifice out, or double play; add specifics in the Other Result note when needed. This app does not track bases, runs, outs, or score.

If a pitcher changes during a plate appearance, pitch history credits each pitch to its pitcher, and the final outcome shows the pitcher on the last recorded pitch. Walks/strikeouts shown are observed finishing outcomes, not official statistical attribution for inherited counts. Use Correct Count for an inherited or missed count; corrections appear in the event log. Undo removes the most recent recorded game event (including a count correction or Other Result) and restores the previous count and hitter.

Automatic saving uses this browser on this device only. It does not sync. Private browsing, browser cleanup, or changing the site address can prevent or remove saves. Download Game Backup regularly; it includes a readable text summary and a restorable JSON backup. Restoring replaces the current game only after confirmation.
